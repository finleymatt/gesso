# Gesso

An artist-community marketplace where every purchase pays the collector back in the artist's own chips. Chips rise as an artist gains collectors and can be spent on any work.

- `site/` is the static site (plain HTML, CSS and JS, no build step).
- Run it locally with `python .claude/serve.py 5178 site` and open http://localhost:5178.
- Pushing to `main` deploys `site/` to GitHub Pages.
